# K Parthasarathi Portfolio — PASWIN & DONGLE

A 3D-enhanced, mobile-first portfolio website built with React + Three.js.

## Features
- **3D Hero Scene** — Metallic gold sphere with distortion, purple rings, floating particles (Three.js / React Three Fiber)
- **Bottom Navigation** — Hexagonal center button matching the reference image; desktop gets a top nav instead
- **5 Pages** — Home, About, Services, Projects (filterable), Contact
- **Contact** — Direct Call (`tel:`) and WhatsApp deep-link buttons for +91 9941629968
- **Smooth transitions** — Framer Motion page animations, scroll reveals
- **Palette** — Metallic gold, white-soft, and accent purple on deep dark background

## Tech Stack
- React 19 + Vite
- Three.js via @react-three/fiber + @react-three/drei
- Framer Motion

## Getting Started

```bash
npm install
npm run dev        # development server
npm run build      # production build → dist/
npm run preview    # preview production build
```

## Deployment
Upload the `dist/` folder to any static host (Netlify, Vercel, GitHub Pages).
